# Contributing to CyberShield Range

Thank you for your interest in contributing to CyberShield Range.

## Project Goal

CyberShield Range aims to provide an intelligent cybersecurity training and experimentation platform integrating:

* Attack simulation
* Threat detection
* Network monitoring
* Incident response
* AI-assisted security analysis

## How to Contribute

### Reporting Issues

If you find a bug or identify an improvement:

1. Open an issue.
2. Clearly describe the problem.
3. Provide reproduction steps if applicable.

### Suggesting Features

Feature proposals should include:

* Problem description
* Proposed solution
* Expected benefits

### Development Workflow

1. Fork the repository.
2. Create a feature branch.

```bash
git checkout -b feature/my-feature
```

3. Commit your changes.

```bash
git commit -m "Add my feature"
```

4. Push your branch.

```bash
git push origin feature/my-feature
```

5. Open a Pull Request.

## Coding Principles

* Keep code clean and documented.
* Follow project architecture guidelines.
* Prioritize security and maintainability.
* Write meaningful commit messages.

## Research Contributions

Research ideas, papers, architectural suggestions and cybersecurity experiments are welcome.

Thank you for helping improve CyberShield Range.
